# U盘应用管理 v0.3.7 · 全部应用版

双击 `启动.bat`，点击“扫描全部应用”，勾选需要卸载的软件，再确认执行。所有卸载、安装选项默认不勾选。可按名称或发布者搜索；搜索不会清掉已选项，确认窗口会列出全部已选软件。

扫描列表排除微软公司发布的软件，包括传统软件和商店应用；识别发布者英文、中文及商店应用证书中的公司名称，不根据产品名中的 Microsoft 字样排除其他厂商的软件。内部登记仍用于完成状态复查及安装检测，微软项目不会成为可执行的卸载目标。

扫描当前用户和系统级的 32/64 位软件登记、当前用户商店应用，以及常见桌面/开始菜单中的程序快捷方式。没有卸载入口的便携程序会注明原因；不扫描其他用户账户，也不遍历磁盘寻找每一个 EXE。

传统软件使用已登记的卸载器，不再以发布者缺失或产品目录无法核实为由阻止卸载。支持已登记静默入口、MSI、已识别的 NSIS/Inno 卸载器、经验证的 Chrome 安装器以及部分 WinGet 登记。快捷方式指向的程序没有登记入口时，仅查找其同一目录内唯一的卸载程序。“仅静默卸载”默认不勾选，需手动的软件会打开厂商窗口；勾选该选项后跳过需手动项目。静默规则不会保证所有厂商自定义卸载器都没有交互。

可移除的商店应用仅从当前用户移除，不修改系统预装映像或其他用户。第三方共享组件可选择，Windows 决定依赖是否允许移除。系统不可移除项，以及原来要求保留的电脑管家、电影和电视、截图和草图不可勾选。驱动、运行库等显示依赖提示。

保留 QQ、微信、搜狗的自动下载和安装功能，需用户主动勾选。同一软件不能同时卸载和安装。静默规则仍绑定已核实安装包的版本和哈希；官网更新未知包时停止，不猜测参数。

执行前重新扫描并核对机器、用户、选中项及卸载器文件；取消会停止后续动作，不强杀厂商进程，不自动重启。工具不自行删除软件目录或个人数据。厂商卸载界面中的数据选项由用户核对。

静默卸载等待期限为五分钟；厂商仍未结束时停止后续动作并显示处理入口。完成检测由独立只读进程执行，每次最多二十秒且不超过剩余等待期限。卸载主进程正常退出、产品登记消失，且只剩已核实的普通浏览器进程时，可结束等待并保留浏览器。Chrome 的专用成功码 19 与通用成功码 0 均可确认，29 标记为待重启复查；这些专用码不会套用到其他软件。升级前曾强制关闭工具的，在原工具目录覆盖新版文件，启动后点“恢复执行状态”，再重新扫描。恢复只处理本工具的遗留等待，真正仍运行的卸载器或未知进程会列出 PID 和路径。恢复成功不代表软件卸载成功。

使用 Windows 10/11 x64 的 Windows PowerShell 5.1，无需额外安装运行环境。只读扫描不申请管理员权限，执行时申请。日志默认写入工具目录，U盘不可写时使用本地用户日志目录。`演示界面.bat` 禁止执行实际操作。

项目为独立的 Windows 应用管理工具。

v0.3.1 补充 IE 与搜狗的浏览器运行进程识别；360、Firefox、QQ、2345 浏览器需额外匹配当前登记的浏览器主程序路径。浏览器进程的文件信任只使用本机证书和缓存，不访问网页或在线吊销服务；安装包的下载校验规则不变。卸载主进程已退出、原登记已移除且所有遗留成员均为已核实浏览器时，不再等待反馈网页关闭。即使退出码不属于标准成功码，也可结束仅剩浏览器的等待，但结果单独记为“登记已移除”并显示原始退出码，不报完整卸载成功。仍在运行的卸载器、未知进程和尚未移除的登记不能据此放行。

执行结果默认可显示约六条记录，并支持拖动上方分隔线调整高度及滚动查看。
